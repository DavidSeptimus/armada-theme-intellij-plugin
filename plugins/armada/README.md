# Armada Core Themes for IntelliJ-based IDEs

[![Downloads](https://img.shields.io/jetbrains/plugin/d/26844-armada-theme.svg)](https://plugins.jetbrains.com/plugin/26844-armada-theme)

## Description

<!-- Plugin description -->
Armada Core Themes brings the look of JetBrains Fleet's default light and dark themes to IntelliJ-based IDEs. With Fleet deprecated, Armada now also takes its cues from JetBrains Air, so the themes keep evolving alongside JetBrains' current design direction.

This plugin is part of the Armada family of themes, which includes both free and premium themes for JetBrains IDEs, adapted from or inspired by the design aesthetics of JetBrains Fleet and JetBrains Air.
The complete list of Armada premium themes can be found [here](https://plugins.jetbrains.com/plugin/26844-armada-theme/premium-themes).


If you enjoy Armada Core Themes, but are looking for a more colorful UI, you might
consider exploring the [Armada Dark Purple](https://plugins.jetbrains.com/plugin/28726-armada-dark-purple-theme) and [Armada Deep](https://plugins.jetbrains.com/plugin/28727-armada-deep-theme) premium themes. Dark Purple offers an additional color scheme inspired by Fleet's design, and Deep is an original theme built on Fleet's design principles.

### Features

#### Includes Fleet- and Air-inspired Dark and Light UI themes/editor color schemes

#### Supports all three UI generations!

- **Islands**
- New UI
- Classic UI

#### Enhanced Syntax Highlighting

Leverages the [Armada Syntax Highlighter](https://plugins.jetbrains.com/plugin/28723-armada-syntax-highlighter) plugin for more precise syntax highlighting in 13 programming languages and counting.
